# How Fast Will Your Money Double?

A single-page, dependency-free doubling-time calculator (Rule of 72) built for Fintech Anurag.

- Pure HTML/CSS/JS — no build step, no dependencies
- Indian number formatting, category presets, live Rule-of-72 result, growth visualization, category comparison
- Deployed via GitHub Pages

## Local preview
Just open `index.html` in a browser, or run:

```
python3 -m http.server 8000
```

then visit `http://localhost:8000`.
